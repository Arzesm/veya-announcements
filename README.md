# Как отправить сообщение пользователям Veya

Место публикации: https://github.com/Arzesm/veya-announcements

## Отправить новое сообщение

1. Открой редактор: https://github.com/Arzesm/veya-announcements/edit/main/announcements.json
2. Замени содержимое файла примером ниже.
3. Напиши свой заголовок в `title` и текст в `body`.
4. Придумай **новый `id`** для каждого нового объявления. Например, `news-2026-11-20-01`. Подойдут латинские буквы, цифры, точки, дефисы и подчёркивания; без пробелов.
5. В `telegramUrl` оставь ссылку на канал или укажи конкретный пост: `https://t.me/ZaytsevTech/123` (замени 123 настоящим номером поста).
6. Нажми **Commit changes…**, затем **Commit changes**. Сообщение опубликовано. Новую сборку приложения делать не нужно.

```json
{
  "version": 1,
  "messages": [
    {
      "id": "news-2026-11-20-01",
      "title": "Вышла новая версия Veya",
      "body": "В Veya появились новые возможности. Подробности и ссылка на скачивание — в моём Telegram. Спасибо, что пользуетесь приложением!",
      "telegramUrl": "https://t.me/ZaytsevTech"
    }
  ]
}
```

Это шаблон, а не опубликованное объявление о существующем обновлении. Перед отправкой замени текст на актуальный.

## Когда его увидят

Начиная с Veya 0.9.2 приложение проверяет файл **не чаще одного раза в 24 часа**. Время последней попытки сохраняется: перезапуск, открытие окна и выход компьютера из сна не вызывают дополнительных запросов в течение суток. При первом запуске проверка выполняется сразу; если сутки истекли, пока Veya была закрыта или компьютер спал, следующая проверка произойдёт при запуске или пробуждении. После неудачной попытки следующая будет также через сутки. Кэш GitHub может добавить небольшую задержку.

Таким образом, новое объявление может прийти с задержкой до суток при работающем приложении и доступном интернете. В версии 0.9.1 остаётся прежняя проверка раз в 30 минут — для нового расписания нужно установить 0.9.2.

Карточка появляется в открытом активном окне Veya. Если приложение находится в строке меню, она дождётся открытия окна. Она не появляется поверх других программ и не отправляет системных уведомлений.

Когда карточка показана, приложение сохраняет её `id` на компьютере. Она не повторяется после закрытия, повторной проверки или перезапуска приложения. Нажатие на Telegram для этого не требуется. На другом компьютере или после удаления данных Veya сообщение может быть показано снова.

Без интернета новые сообщения не приходят. Последняя успешно загруженная лента сохраняется; ошибка сети не останавливает погоду.

**Пользователям старых сборок нужно один раз установить версию Veya с поддержкой объявлений.** В уже установленную старую сборку эту возможность дистанционно добавить нельзя. Автоматическое обновление приложения здесь не включено.

## Исправить или убрать сообщение

- Исправление текста с прежним `id` не покажет его повторно тем, кто уже видел карточку.
- Чтобы все увидели сообщение заново, опубликуй его с новым `id`.
- Для обычной рассылки проще держать в файле одно актуальное сообщение и заменять его следующим. Можно оставить до 30 сообщений: невиденные будут показаны в порядке списка, по одному.
- Чтобы убрать все объявления, сохрани `{"version":1,"messages":[]}`. Изменение дойдёт после следующей успешной проверки. Уже открытая карточка останется до закрытия; в офлайне может сохраниться ранее загруженная лента.
- Необязательно: добавь в сообщение `"expiresAt":"2026-12-01T00:00:00+03:00"`, чтобы оно больше не показывалось после этой даты. Дата учитывается по часам компьютера пользователя.

## Формат текста

Заголовок — до 100 символов, текст — до 2 000. Обычный текст, без HTML и Markdown. Для новой строки используй `\n`, для кавычек внутри текста — `\"`. Сохраняй запятые и двойные кавычки, как в примере. `version` остаётся **1** — это формат ленты, а не версия приложения.

Кнопка всегда называется «Перейти в Telegram». Разрешены только HTTPS-ссылки на канал `ZaytsevTech` и его посты. Токены GitHub, пароли и ключи приложению не нужны.

Репозиторий публичный: текст объявлений виден всем. Сохранённые в приложении отметки о показе остаются на компьютерах пользователей и не отправляются автору. Статистики просмотров нет.

## Для разработчика

Адрес ленты зафиксирован в `app/announcements.json`. Не меняй имя аккаунта, репозитория, ветки `main` или файла `announcements.json`: установленные приложения читают именно этот адрес.

Локально проверить файл перед публикацией: `node scripts/check-announcements.mjs announcements/example.json`. Сам по себе локальный файл не отправляется пользователям — публикация происходит при сохранении файла **на GitHub**.
